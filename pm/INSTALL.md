# pm setup

Not installable yet. The `pm` on `PATH` is the frontier deployment at
`~/.local/libexec/pm`, and it stays that way until the rewrite passes its parity
gate and the operator runs the cutover.

This guide gains its setup, verification, disabling and removal steps with the
rewrite's integration ticket. The cutover itself is a separate operator-run
procedure and is written with the instruction-delivery epic.
